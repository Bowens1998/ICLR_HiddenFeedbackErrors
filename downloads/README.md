# Download materials

The [OSF materials page](https://osf.io/csgra/files?view_only=280626d2fc5e44c9b72620d0a2ffd0ee) is available without an account.

- `hidden_feedback_code.zip` contains source code, configurations, plotting inputs, and saved analysis arrays.
- `hidden_feedback_reproduction.zip` contains the same code plus all nine experiment archives.
- `SHA256SUMS.txt` lists the checksums for both packages.

Download the package you need, verify its checksum against [SHA256SUMS.txt](SHA256SUMS.txt), and extract it into a new directory. The reproduction package already includes the `archives/` directory expected by `verify_saved_evidence.py`.

The [code package](hidden_feedback_code.zip) is also available in this repository. The [archive inventory](../ARCHIVE_MANIFEST.json) describes the experiment packages inside the reproduction ZIP.
